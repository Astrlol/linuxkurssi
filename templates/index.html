2. How does the counter work?

  • Database: MySQL, running as its own service on the server and started automatically by systemd.
  • Storage: every page load inserts a row with a timestamp into the visits table. The number shown is the row count (SELECT COUNT(*)).
  • Stack: Nginx → Gunicorn → Flask (Python) → MySQL. The database password is stored on the server, not in GitHub.

3. Restart test

Before rebooting the virtual machine (sudo reboot) the counter was 8. After the reboot Nginx, MySQL and the Python app started automatically, the page opened normally and the counter continued from 9.
