2. Commands I used

date

Shows the current date, time and time zone.

uptime -p

Shows how long the server has been running. The -p option prints it in a readable form, e.g. "up 5 hours, 3 minutes".

df / | tail -n 1 | awk '{print $5}' | cut -d'%' -f1

Shows the usage percentage of the root filesystem. df / prints a table for the root filesystem, tail -n 1 keeps only the last line, awk picks the 5th column (Use%) and cut removes the % sign, so the result is a plain number such as 4.

free --mega | grep Mem | awk '{print $7}'

Shows the available RAM in megabytes. grep picks the Mem: line and awk prints the 7th column (available). Total RAM is the 2nd column.

3. How it works

Script: status.sh runs the commands above and stores each result in a variable using command substitution ($(...)). It then reads template.html, replaces the placeholders such as {TIME} with the values using sed, and writes the result to /var/www/html/viikko3/index.html, where Nginx serves it.

Disk space status: the function DISK gets the usage percentage and uses an if statement with -ge 80: below 80 % it returns OK, 80 % or more returns WARNING.

Schedule: FILL IN after the schedule is set up.

  • Automatic updates: The generation time changed from 16:30:00 to 16:31:00 and 16:32:00 without running the script manually.
  • Reboot test: After sudo reboot the page opened normally and the report kept updating every minute.”

5. What I learned

For comparing numbers in Bash, -gt means "greater than" and -ge means "greater than or equal". The assignment says WARNING at 80 % or more, so -gt 80 would have wrongly given OK at exactly 80 %. Testing the boundary value 80 is what shows the difference.
