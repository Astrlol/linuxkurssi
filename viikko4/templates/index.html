03 How B was created

  1. Snapshot of A Launched as a new cPouta instance with the same key and security group, plus its own floating IP. Hostname: gigalinux.
  2. Turned off A's jobs laskuri and status-report.timer disabled. B must never write to its own database.
  3. New MySQL identity Moved away the copied auto.cnf so MySQL generated a new server_uuid. Replication refuses two servers with the same one.
  4. Private network Both servers are in the default security group, which lets its members talk to each other. Nothing extra opened to the internet.

Why replication does not replace backups

Replication copies every change within seconds, mistakes included. Delete all rows on A and they are gone from B a moment later. It keeps no history to go back to. Backups are separate copies from different points in time. Replication protects against losing a server; backups protect against losing data.

How the backup script works
  • cron line: 15 * * * * varmuuskopio /usr/local/bin/nettisivun-varmuuskopiointi
  • Runs tar -czf - -C /var/www html on A over SSH and streams the archive to B (key auth, BatchMode=yes, private network).
  • Writes to .inprogress first and renames only when complete, so a broken file never looks like a backup.
  • Logs OK with size and tar exit code, or FAIL. Deletes everything older than the 24 newest.
  • tar exit code 1 ("file changed while reading") counts as OK, because the Week 3 report on A changes every minute.
How replication was set up
  • A: server-id 1, gtid_mode ON, MySQL listening on 127.0.0.1 and its private IP only.
  • B: server-id 2, gtid_mode ON, read_only + super_read_only. Only the replication thread can write.
  • B seeded with mysqldump --single-transaction --set-gtid-purged=ON from A, then started with SOURCE_AUTO_POSITION=1 and SOURCE_SSL=1.

08 Problem I solved

Problem
After setting bind-address = 127.0.0.1,192.168.1.33 on A, MySQL still listened only on 127.0.0.1.
Cause
mysqld --print-defaults showed the setting twice. My file 99-replikointi.cnf was read before Ubuntu's mysqld.cnf (digits sort before letters), and the last value wins.
Fix
Renamed it to replikointi.cnf so it loads last. ss -tlnp then showed both addresses.
Lesson
Check what a service actually reads, and run mysqld --validate-config before restarting a live database.
